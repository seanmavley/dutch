Handelsregister Intelligence & Recognised Sponsors

Created by KhoPhi to help easily navigate the IND Public Register of Recognised Sponsors for visa and skilled worker sponsorship in the Netherlands.

Categorizes over 13,000 organisations into distinct industries (Technology, Healthcare, Finance, Energy, Manufacturing, Retail, etc.) using AI-assisted enrichment to allow fast search and discovery.

Source code is open source and available on GitHub.
